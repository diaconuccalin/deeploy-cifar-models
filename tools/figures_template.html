How it is quantized

Every layer is an integer Conv or Gemm followed by a RequantShift (RQS) that applies the folded BatchNorm and activation scale: y = clip((x·mul + add + div/2) / div) with a power-of-two div. Layers with ReLU output uint8 (0…255); linear projections and the logits output int8.

Same graph as DeeployTest

The operators and their order are those of Deeploy's reference CCT/FP32/CCT_2_32_32_128 test, with trained weights written in. One change: each Gemm has its own bias tensor, where the reference shared one. On Siracusa it runs with L3 as the default memory level and L1 = 128 kB.

Accuracies are on the full 10,000-image CIFAR test sets; for the int8 models they come from a bit-exact integer reference of the deployed graph. Cycles are GVSoC runs of Siracusa through Deeploy's tiled flow, 8 cores, upstream devel at e4519eb7. Parameter counts are trainable parameters.
